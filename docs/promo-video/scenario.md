## 촬영 전 확인 (2026-09-28 캡처 중 발견)

1. **날씨 연동 고장:** 기상청 예보 API가 `403`을 반환합니다. 그래서 실내 추천이 동작하지 않고, 화면에는 "예보 제공 범위 밖이라 날씨 필터 없이 추천했습니다"라는 **잘못된 안내**가 뜹니다. API 키나 활용 신청 상태를 확인해야 합니다.
2. **도로망 서버가 외부 Overpass API에 의존합니다.** 처음 보는 지역 조합은 OpenStreetMap 도로 데이터를 실시간으로 받습니다. 이번에 타임아웃(120초)과 연결 거부가 나서, 채팅 흐름에서 **"AI 상세 일정 받기"가 "요청을 처리하지 못했어요"로 실패**했습니다. 촬영(특히 라이브 녹화) 전에 경기북부 도로망을 미리 받아 두는 개선을 권장합니다.
3. **추천 목록에 골프장(CC)·시장 같은 비관광지가 섞입니다.** 편집에서 크롭하거나, 추천에도 "관광지만" 필터를 적용하세요.
4. 헤드리스 캡처에서는 상세 페이지의 **위치 지도가 비어 있습니다.** 실제 브라우저에서 따로 녹화하세요.
